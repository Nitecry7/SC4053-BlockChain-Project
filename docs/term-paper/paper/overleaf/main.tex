\begin{abstract}
% Stage 3. Pointers: EV = evidence/README.md. Rows S1, C1b, C3d, M2a, M1d.
Decentralized exchanges can account for every token yet let traders lose value to whoever orders transactions.
We study this economic security problem in our own fully on-chain limit order book, whose loops are bounded for gas and whose orders and stop triggers are public.
Using deterministic Foundry tests on a local chain, we reproduce and measure four attacks. % EV E1 to E4, E8, E9
Ten dust orders exhaust a buyer's ten-fill budget, so in our tests the buyer pays up to 5.0 extra quote on a 15.0 trade, exactly the attacker's profit before gas. % EV E1 33% row
A one-lot self-trade fires a stop order, and a stop can be sniped for half of its proceeds inside a single transaction that no keeper can interrupt. % EV E2, E9 atomic
A wall of 101 dust bids blocks new bids, at 8.4 times the defender's gas. % EV E4; COST_MODEL griefing table
In a research copy of the engine, cancelling a still-crossed remainder removes the sandwich and snipe profits but alone turns theft into a $10^{9}$-round delay; adding a minimum order size bounds it to 10 rounds. % EV E5, E7, E10
We recommend both changes together, plus a redesign of stop activation.
\end{abstract}
