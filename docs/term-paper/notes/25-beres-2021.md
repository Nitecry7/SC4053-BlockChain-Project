## 4. Limits for an on-chain order book
- About user deanonymization, not ordering attacks or MEV; nothing on DEX order books, fills, or stop orders.
- Ethereum L1 data up to 2020-04-04 only (p. 3, Sec. 4), pre EIP-1559, so the gas price quasi-identifier may not transfer as-is (gas price setting described on p. 6, Sec. 6, "Gas price distribution").
- Ground truth is small (129 ENS pairs) and Tornado ground truth is heuristic (p. 4, Table 1 note).
- Read the arXiv preprint, not the 10-page IEEE version.

## 5. Claim check
- Summary given: "Ethereum accounts can be profiled through behavioural quasi-identifiers."
- Verdict: supported
- Evidence: abstract describes patterns that "characterize only a limited set of users" applied as "quasi-identifiers" in address deanonymization (p. 1). The quasi-identifiers are time-of-day activity, gas price selection, and transaction graph position (p. 6, Sec. 6). Results: profiling links addresses of the same user "significantly better than random guessing"; best combination yields 1.6 bits, anonymity set reduced by a factor of about 3.03 (p. 7). Conclusion repeats that these quasi-identifiers link addresses owned by the same user (p. 15, Sec. 10). Note: the strongest identifier is graph position (node embeddings), which is structural rather than purely "behavioural"; time-of-day and gas price performed weaker (p. 7, Sec. 6, "Evaluation").
