## 4. Limits for an on-chain order book
- Not an EVM smart contract: model assumes validators run the matching with order-fair broadcast (of-ABC); our book runs in a contract on a chain without fair ordering.
- Empirical numbers are a simulation over dYdX order book data (an exchange that uses CLOB), not a measured FBA deployment.
- Welfare loss is measured as realized spread, a market-quality metric; it does not count MEV attacks such as our C1 to C4 directly.
- No stop orders, no fill caps, no gas costs.
- The headline "21% to 37%" is a CLOB-over-FBA cost increase; the abstract phrases it as FBA "can reduce transaction costs by 21% -37%", which is not the same arithmetic (a 37% increase is about a 27% reduction). Quote the body phrasing.

## 5. Gap question answered
- Question(s): a, d.
- Answer from this source: a: analyses front-running for order-book DEXs (not AMMs) in a game-theoretic model where front-runners act after seeing pending orders (p. 3 Sec.
